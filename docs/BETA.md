# Бета-версия StudentDeals.uz

## Обзор

StudentDeals.uz находится в закрытой бета-версии. Это означает, что платформа активно разрабатывается и тестируется с ограниченной группой пользователей.

## Доступ к бета-версии

### Для пользователей
- Бета-версия доступна по адресу: `/[locale]/beta` (например, `/ru/beta` или `/uz/beta`)
- Поддерживаются языки: русский (ru) и узбекский (uz)
- Форма обратной связи интегрирована на странице

### Для разработчиков
- API endpoint: `POST /feedback`
- Rate limiting: 5 запросов в минуту на IP
- Валидация: email (опционально), message (5-2000 символов), rating (1-5, опционально)

## Система обратной связи

### Форма обратной связи
- **Email** (необязательно): для получения ответа
- **Сообщение** (обязательно): 5-2000 символов
- **Оценка** (необязательно): 1-5 звезд
- **Автоматическая отправка**: GA событие `feedback_submitted`

### API Endpoints

#### POST /feedback
```json
{
  "email": "user@example.com", // опционально
  "message": "Ваше сообщение", // обязательно, 5-2000 символов
  "rating": 5 // опционально, 1-5
}
```

**Ответ:**
```json
{
  "success": true,
  "feedbackId": "cuid_string",
  "message": "Thank you for your feedback!"
}
```

#### GET /feedback/stats
**Ответ:**
```json
{
  "total": 42,
  "averageRating": 4.2,
  "distribution": {
    "1": 2,
    "2": 1,
    "3": 5,
    "4": 15,
    "5": 19
  }
}
```

## Развертывание

```bash
NEXT_PUBLIC_API_URL=https://api.studentdeals.uz
NEXT_PUBLIC_GA_ID=G-XXXXXXXXXX

# Backend (Render)
DATABASE_URL=postgresql://...
CORS_ORIGIN=https://studentdeals.uz,https://*.vercel.app
```

### Миграции базы данных
```bash
# Создание миграции для feedback
pnpm --filter api run migrate:feedback

# Применение миграций
pnpm --filter api run prisma migrate deploy
```
