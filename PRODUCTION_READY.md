## 🚀 Quick Deploy

### 1. Deploy API (Render)

```bash
# Via Render Dashboard:
# 1. Create new Web Service
# 2. Connect GitHub repo
# 3. Set build: cd apps/api && pnpm install && pnpm build
# 4. Set start: cd apps/api && pnpm start:prod
# 5. Add environment variables (see apps/api/env.example)
# 6. Deploy
```

### 2. Deploy Web (Vercel)

```bash
# Via Vercel Dashboard or CLI:
vercel --prod

# Set environment variables (see apps/web/env.example)
```

### 3. Run Migrations

```bash
cd apps/api
DATABASE_URL="<production-url>" pnpm exec prisma migrate deploy
```
